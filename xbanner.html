SentinelIoT

Sistem Deteksi Dini Kebakaran Berbasis
Fuzzy Logic dengan Monitoring Real-Time

Tim: Ahmad Fauzi · Dhimas Raka · Zahra Nuraini
Teknologi Informasi — Fakultas Vokasi, Universitas Brawijaya
Permasalahan
01 Kebakaran di gedung/gudang sering terlambat terdeteksi karena tidak ada sistem peringatan dini.
02 Monitoring suhu, gas, dan api masih dilakukan manual, tidak real-time dan rentan human error.
03 Tidak ada sistem otomatis yang dapat mengaktifkan exhaust fan dan buzzer saat bahaya terdeteksi.
Solusi

SentinelIoT adalah sistem pemantauan kebakaran otomatis yang menggunakan Fuzzy Logic Sugeno untuk menentukan level bahaya dan mengontrol aktuator secara cerdas.

Fungsi Utama
Monitoring gas, asap, suhu, dan api secara real-time melalui dashboard web.
Manfaat
Deteksi dini, respons otomatis, dan notifikasi langsung ke pengguna.
